## Ideas y material disponible

- Clientes: aplicación web (instalable en móviles como PWA) y chatbot de mensajería: Telegram en las etapas de prueba y WhatsApp desde el lanzamiento comercial.
- Servicios externos: proveedores de LLM, API de Telegram, APIs de cotizaciones e inflación.
- Detalle técnico: [[_Relevamiento del código]].
- Cliente: navegador web (Next.js/React) y la app de Telegram. La PWA todavía no está implementada (no hay manifest ni service worker).
- Servidor: API REST en Kotlin/Spring Boot (JVM 21), PostgreSQL 16 con Row-Level Security, Keycloak (OAuth2/JWT), almacenamiento S3, contenedores Docker.
- Seguridad ya implementada: autenticación federada con Keycloak, validación de pertenencia al espacio de trabajo en cada request y aislamiento de datos por espacio de trabajo con RLS.
