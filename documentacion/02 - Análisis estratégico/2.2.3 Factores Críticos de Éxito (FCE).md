## Respuesta

<!-- Todo lo que esté debajo de este título es el texto que se compila al documento final. -->

Para lograr que el usuario opte por usar el servicio propio se debe garantizar la precisión de las herramientas de IA; las herramientas que se le ofrecen al LLM no pueden fallar al registrar montos, un error pequeño podría romper la confianza del usuario.

Adicionalmente se debe mantener la disponibilidad multicanal de baja latencia, asegurándose de que el chatbot responda de forma rápida y que la infraestructura soporte el uso del sistema tanto via aplicaciones de mensajería como la propia.

Finalmente, debe haber una actualización dinámica del contexto macroeconómico. Las APIs que alimentan los tipos de cambio y los índices de inflación deben ser precisas y estar siempre en línea.
