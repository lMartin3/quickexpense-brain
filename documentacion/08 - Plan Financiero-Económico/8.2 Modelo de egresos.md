# 8.2 Modelo de Egresos

> [!quote] Consigna
> Se encuentran divididos en costos de producción, costos de comercialización y ventas, y costos de administración. A su vez serán divididos en costos fijo y variable. Si el proyecto contemplara la contratación de una deuda bancaria, es necesario incluir un apartado de egresos por concepto de costos financieros.

## Qué se espera

Costos de producción, comercialización y administración, cada uno separado en fijos y variables. Costos financieros si hay deuda.

## Ideas y material disponible

- Variable principal: consumo de tokens de APIs de IA, dolarizado (1.11, 3.1).
- Infraestructura y hosting, APIs de cotizaciones e inflación, mensajería (WhatsApp/Telegram).
- Marketing: [[6.6.1 Planificación estratégica de las acciones de comunicación]].
- Servicios que usa hoy el código (costos a relevar): API de Anthropic (Claude Haiku 4.5), API de OpenAI (Whisper), servidor de producción, almacenamiento S3, Keycloak.
