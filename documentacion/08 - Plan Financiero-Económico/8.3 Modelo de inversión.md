## Respuesta

<!-- Todo lo que esté debajo de este título es el texto que se compila al documento final. -->

La inversión corresponde a la etapa preoperativa, de octubre de 2026 a mayo de 2027, en la que se completa el producto y se realizan las pruebas Alpha y Beta, más el capital de trabajo necesario para el inicio de la operación. Se financia en su totalidad con capital propio del fundador.

El desarrollo realizado antes de octubre de 2026 no se incluye: es un costo hundido que no cambia según se ejecute o no el proyecto.

| Rubro | Detalle | USD |
| ---------------------------------- | ------------------------------------------------------------ | ----- |
| **Activos fijos** | No se adquieren: se utiliza el equipo informático del fundador y la infraestructura se alquila | 0 |
| **Activos diferidos (intangibles)** | | **4.264** |
| Desarrollo del software | 8 meses de dedicación del fundador, valorizada como en 8.7 | 3.467 |
| Servidor durante el desarrollo y las pruebas | 8 meses, con IVA | 290 |
| Inteligencia artificial durante el desarrollo y las pruebas | 8 meses, con IVA | 484 |
| Registro de la marca | Solicitud ante el INPI en una clase: 100 UMAPI [@inpi2026res75], a un valor inicial de $360 por UMAPI [@beccar2026umapi] | 23 |
| **Capital de trabajo** | Un mes de egresos de caja del inicio de la operación | **201** |
| **Total** | | **4.465** |

El capital de trabajo se calculó con el método del período de desfase. Como las suscripciones se cobran en el momento (ver 8.1), el desfase surge de los costos fijos que se pagan antes de que haya ingresos suficientes para cubrirlos; se tomó un mes de egresos de caja. Ese capital no alcanza para cubrir los déficits operativos del horizonte (ver 8.8), que el fundador también debe cubrir con aportes propios.

No hay costos de constitución de una sociedad, porque el emprendimiento funciona como persona humana inscripta en el monotributo (ver 9.4).
