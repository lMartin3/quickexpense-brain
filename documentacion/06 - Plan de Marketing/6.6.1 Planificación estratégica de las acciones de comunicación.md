## Respuesta

<!-- Todo lo que esté debajo de este título es el texto que se compila al documento final. -->

La comunicación se apoya exclusivamente en **canales orgánicos**, sin inversión en publicidad paga. La decisión responde a los recursos de un emprendimiento unipersonal financiado con capital propio y a la escala de las metas del primer año (150 usuarios registrados, ver 6.1), que no requieren campañas masivas. El costo de las acciones es el tiempo del fundador, ya incluido en la valorización de su dedicación (ver 8.7).

**Acción 1: contenido en redes sociales.**

| Campo | Descripción |
| -------------------------- | ------------------------------------------------------------ |
| Comunicación | Publicaciones orgánicas en Instagram y TikTok |
| Objetivo | Dar a conocer el producto, informar sobre su funcionamiento y persuadir de que registrar los gastos puede ser fácil |
| Tipo | De producto y educativa |
| Estilo | Racional y demostrativo: videos cortos que muestran cómo se registra un gasto con un audio o una foto, y contenidos sobre finanzas personales en un contexto inflacionario |
| Medio | Instagram y TikTok, con foco geográfico en Rosario |
| Características generales | Frecuencia semanal; tono cercano; invitación a probar gratis el plan premium durante un mes |
| Costo estimado | USD 0 (tiempo del fundador) |

**Acción 2: contenido mensual sobre la inflación.**

| Campo | Descripción |
| -------------------------- | ------------------------------------------------------------ |
| Comunicación | Publicación mensual atada al dato de inflación que publica el INDEC |
| Objetivo | Reforzar el posicionamiento del producto como la herramienta que tiene en cuenta la inflación (ver 6.3) |
| Tipo | Institucional y de producto |
| Estilo | Racional, con datos: cuánto aumentaron los gastos habituales frente a la inflación del mes y cómo lo muestra la aplicación |
| Medio | Instagram y TikTok |
| Características generales | Aprovecha un evento mensual que ya concentra la atención del público |
| Costo estimado | USD 0 (tiempo del fundador) |

**Acción 3: comunicación directa con los usuarios de las etapas de prueba.**

| Campo | Descripción |
| -------------------------- | ------------------------------------------------------------ |
| Comunicación | Mensajes directos a los participantes de la encuesta que dejaron un contacto y a los usuarios Alpha y Beta |
| Objetivo | Convocar a las etapas de prueba, recoger retroalimentación y convertirlos en los primeros usuarios del lanzamiento |
| Tipo | Relacional |
| Estilo | Personal |
| Medio | Correo electrónico y mensajería |
| Características generales | 16 de los 31 encuestados dejaron un contacto [@luraschi2026encuesta] |
| Costo estimado | USD 0 |

**Acción 4: promoción dentro del producto.**

| Campo | Descripción |
| -------------------------- | ------------------------------------------------------------ |
| Comunicación | Promoción de ventas dentro de la aplicación y del asistente |
| Objetivo | Convertir al plan premium a los usuarios en prueba y a los gratuitos |
| Tipo | De producto |
| Estilo | Racional: se avisa al usuario antes de que termine la prueba qué funciones perderá, y se ofrece el plan premium cuando un usuario gratuito llega al tope diario de mensajes o intenta usar una función premium, como WhatsApp o un espacio compartido |
| Medio | Aplicación web, notificaciones, correo electrónico y asistente |
| Características generales | Prueba gratuita de un mes, plan anual con dos meses sin cargo y descuento para los usuarios Alpha y Beta (ver 6.5.2) |
| Costo estimado | USD 0 de forma directa; la prueba gratuita cuesta unos USD 6,76 de IA y WhatsApp por cada usuario en prueba activo (ver 8.2) |

**Plan de medios del primer año.**

| Período | Acciones |
| ---------------------------------- | ---------------------------------------------------------- |
| Marzo a mayo de 2027 (prelanzamiento) | Apertura de las cuentas en redes sociales; contenido que anticipa el lanzamiento; comunicación directa con los usuarios de la Beta |
| Junio de 2027 (lanzamiento) | Anuncio del lanzamiento y de la prueba gratuita; mayor frecuencia de publicaciones |
| Julio de 2027 a mayo de 2028 | Publicaciones semanales (acción 1), publicación mensual con el dato de inflación (acción 2) y promoción dentro del producto (acción 4) |

No hay fuerza de ventas: la venta es de autoservicio, desde la propia aplicación. Tampoco se tercerizan servicios de comunicación.
