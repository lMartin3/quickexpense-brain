La idea del proyecto es una aplicación web de finanzas personales destinada a personas en Argentina, principalmente jóvenes y adultos de 18 a 35 años. Esta aplicación busca destacar del resto mediante dos fundamentos:
1. La integración con inteligencia artificial para facilitar las tareas de ingreso y procesamiento de información
2. La  personalización para la región (Argentina) teniendo en cuenta el contexto económico local con la devaluación e inflación

# Funciones principales
## Gestión básica de cuentas, movimientos y categorías
La aplicación cuenta con una gestión básica de cuentas, movimientos y categorías para cada uno; permitiendo crear cuentas de ingreso (ej: trabajo), de activos (ej: billetera, cuenta bancaria, billetera crypto), de deuda (ej: plata que se le debe a un amigo o familiar), de gastos (ej: supermercado, kiosco, restaurante, etc) y de equidad.

## Chatbot
Casi todo lo que se puede realizar en la aplicación mediante la interfaz web se puede realizar mediante un chatbot de Telegram (al cual en el futuro probablemente se le sume un chatbot de WhatsApp). Este chatbot interpreta mensajes de texto así como PDFs, imágenes y audios. La idea hasta ahora es que simplemente sea una interfaz para interactuar con el programa con lenguaje natural y de manera práctica.

## Gestión de espacios de trabajo y usuarios múltiples
La aplicación admite múltiples espacios de trabajo dentro de cada cual se crean las cuentas, movimientos, etc. Un espacio de trabajo puede tener más de un usuario, permitiendo que varias personas colaboren en el mismo seguimiento financiero

## Seguimiento de inflación y tipo de cambio
La aplicación hace un seguimiento del porcentaje mensual de inflación en el mes a mes y del tipo de cambio (dolar estadounidense) para poder mostrar el cambio en el valor de las tenencias del usuario con efectividad

## Reportes de gastos
La aplicación permite crear reportes de gastos mensuales para ayudar a los usuarios a entender cuánto y en qué gastaron su dinero con mayor exactitud. Estos reportes se crean en base a la información presente de los movimientos.

## Gastos recurrentes
Se pueden registrar gastos que ocurren cada mes o cada cierto periodo de tiempo para evitar la carga manual y aumentar la predictibilidad de los gastos en los meses siguientes

## Herramienta de presupuesto
La aplicación cuenta con una herramienta que permite crear un presupuesto mensual en base a gastos fijos recurrentes y estimaciones de gastos variables, las cuales cuentan con asistencia por parte de IA.
